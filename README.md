# Spring Framework Practice 🌱🚀

This repository contains my Spring Framework practice programs created while learning Java backend development and understanding enterprise application development concepts.

## About

This repository includes practice examples of Spring Framework concepts such as Inversion of Control (IoC), Dependency Injection (DI), Spring Beans, configuration, and basic application development.

## Topics Covered

* Introduction to Spring Framework
* Spring Architecture
* IoC (Inversion of Control)
* Dependency Injection (DI)
* Spring Container
* Application Context
* Bean Lifecycle

## Dependency Injection

Practice with:

* Constructor Injection
* Setter Injection
* Field Injection
* Loose Coupling
* Tight Coupling

## Spring Beans

* Bean Configuration
* Bean Creation
* Bean Scope
* Bean Management

## Spring Configuration

* XML Configuration
* Annotation Based Configuration
* Component Scanning
* @Component
* @Autowired
* @Configuration
* @Bean

## Practice Programs

Includes:
